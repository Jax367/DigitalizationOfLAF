# 只读客户端 0.7.2 存档

此目录保存展开闪动修复和独立窗口试验前的完整共享源码、构建准备脚本及只读端包配置，manifest.json 记录源码校验值。存档不包含账号密码、设备凭据或缓存记录。

需回退时，先退出客户端，将 src 复制回 laf-desktop/src，将 prepare.cjs 复制回 laf-desktop/scripts/prepare.cjs，将 package.json 与 package-lock.json 复制回 laf-viewer，重新准备源码及打包。回退会撤销此存档之后的客户端改动，请先保存当前源码。

原安装包仍保留在 laf-viewer/dist/LAF-Viewer-Setup-0.7.2.exe。
