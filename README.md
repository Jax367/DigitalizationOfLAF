# 校园失物招领框架 0.7

当前结构为服务端、Windows 只读桌面小窗、网页编辑管理端。编辑者和管理员直接在浏览器操作，无需安装编辑客户端。

## 本机运行与升级

已有服务请先停止，再从根目录运行：

```powershell
.\Start-Server.ps1
.\Start-Client.ps1
.\Start-Editor.ps1
```

服务启动自动应用数据库迁移，包括新增的编辑权限字段；既有账号和记录保留。网页地址为 http://127.0.0.1:8787/editor/。Start-Editor.ps1 现在打开浏览器，旧 Start-Client.ps1 -Editor 也转到网页。首次使用可运行 Initialize-Admin.ps1 初始化管理员，没有默认密码；已有管理员无需再次初始化。

初次开发需 Node.js 22.12+，分别在 laf-backend 和 laf-desktop 安装依赖。当前机器可使用 .tools/bin/npm.cmd。服务端默认只监听本机；局域网运行 Start-Server.ps1 -Lan，网页访问 http://服务器IP:8787/editor/，只读端设置同一服务器地址。

## 只读桌面窗口

安装包：laf-viewer/dist/LAF-Viewer-Setup-0.8.1.exe。请先从托盘退出旧版再升级。也可携带完整 win-unpacked 目录运行 LAF-Viewer.exe。

小窗透明且无系统标题栏，拖动标题区域移动；拖动四边或四角调整宽高，松开自动保存，下次启动恢复。最小为 340×360，展开详情时最小宽度为 680；尺寸受当前显示器工作区限制。列表适应窗口宽度，展开与收起详情保留列表宽度。

设置包含服务器地址、刷新间隔、置顶、自启、关闭到托盘、本地记录目录、图片容量、白色/黑色主题及 0–100% 背景透明度。文字和图片不随背景透明度消失。目录可以粘贴绝对路径或通过浏览选择。

每条业务记录仅含：序号 id、名称 title、描述 description、出现楼层 floor、录入时间 created_at、认领状态 status、关联图片 image_id。图片保存在独立 R2 存储，image_id 通过 images 表引用文件。

已获批准的设备先显示本地记录，再每 60 秒默认检查授权并刷新，只获取未认领完整记录 GET /api/items?status=found。列表不显示图片，点击单条记录在侧边显示详情和图片，蓝色标记当前条目，同时仅展开一条并带渐变动画。

本地记录默认在 %APPDATA%/laf-viewer/，指定目录后存于 laf-cache/<服务器哈希>/records.json，图片另存 images。切换目录复制当前记录并保留旧副本。对已缓存而不在未认领列表的序号请求 cache-status 小型状态信息：已认领立即隐藏，认领满七天后清除本地记录及无引用图片；服务器删除的记录同步时立即清除。启动和刷新均执行到期清理，关闭程序期间不运行清理任务。断网无法获知新状态，保留最近一次记录。

## 网页编辑管理

浏览器中可申请账号、登录、发布记录、选择图片上传预览、编辑、变更认领状态、删除和修改密码。申请固定为待审批编辑者；管理员批准后才可登录使用。图片支持 PNG/JPEG/WebP，最多 5 MB。

管理员在账号审批页批准、拒绝、停用账号，也可单独撤销或恢复编辑权限。撤销权限立即注销该账号所有旧会话；重新登录可以只读浏览，但创建、修改、删除和上传被服务端拒绝。停用账号连登录和认证访问也不允许。界面与 API 都执行权限检查；管理员账号不能通过该页修改权限。

操作日志由服务端记录操作人、时间、类型、目标和详情：注册、登录、退出、密码变更、记录查询/详情、创建/修改/删除、图片上传/删除、审批、权限变更及被拒绝的编辑操作。修改记录和权限包含前后内容，不保存明文密码或会话令牌。设备同步不逐次记录，设备申请和审批单独记录。只有管理员可查询日志，支持操作人、类型、UTC 日期筛选、分页和详情查看，网页不提供修改或删除日志入口。

网页由服务端 /editor/ 提供，登录使用 HttpOnly、SameSite=Strict 会话 Cookie，HTTPS 下设置 Secure；页面刷新保留登录，最长 24 小时。接口仍兼容 Bearer 会话。密码使用随机盐 PBKDF2-SHA256，数据库仅保存令牌哈希；密码更改和账号状态/权限更改会注销既有会话。

旧 laf-editor/src、旧安装包和 laf-desktop 的编辑桌面模块为历史参考，已停止生成与打包；不要继续部署旧编辑 EXE。laf-editor 的 npm start 仅打开网页。

## 数据、验证与扩展

实际本地 D1/R2 数据在 laf-backend/.wrangler/state/；停服后备份整个目录及 .dev.vars。第四次迁移为账号增加 can_edit，不改变物品七个业务字段。第三次迁移旧字段快照保留在 _legacy_items_v03，认领时间独立存于 item_claims。

已验证严格 TypeScript、46 项原 API 检查、33 项网页权限/日志/会话检查、浏览器 GUI 的上传编辑与撤权、只读缓存及 GUI 设置/缩放。测试使用独立 .test-state、8790 端口和桌面测试 profile，不修改实际账号和记录；未实际安装或重启电脑验证自启。

开发入口：服务端 src/routes 与 src/services/auth.ts；网页 laf-backend/public/editor/{index.html,app.js,admin.js,styles.css}；桌面共享源码 laf-desktop/src，生成到 laf-viewer/src。数据库使用 migrations 做后续无损升级。

桌面构建在 laf-desktop 运行 npm run build，仅生成只读端；node scripts/verify-packages.cjs 验证包。npm test 与 npm run check 检查桌面逻辑；npm run test:desktop 验证缩放及设置。服务端 npm run typecheck、npm test、node scripts/web-smoke.mjs；网页 GUI 在 laf-desktop 运行 node node_modules/electron/cli.js scripts/web-editor-smoke.cjs，要求独立测试服务已运行。

云端使用 Workers+D1+R2，正式示例默认适配 Workers Free，省略自定义 CPU limits，后台按小批量清理，保留密码强度、设备审批和配额保护。配置真实资源、域名、密钥后部署，网页静态资源一并部署。免费上线流程和 CPU 云端验收见 [部署说明](laf-backend/DEPLOYMENT.md)。当前没有进行云端部署，尚未确认真实云端调用满足 10ms CPU 限制。框架保留分页/增量同步、冲突版本控制、分类、批量导入、孤立图片回收和备份扩展位置。

## 0.6 只读访问组与设备审批

升级需停止服务后重新运行 Start-Server.ps1，自动应用 0005_reader_devices.sql，并安装 0.6.0 只读客户端。现有编辑账号和物品保留；旧只读端不再能匿名同步。

1. 管理员登录网页，进入「只读设备管理」，创建访问组（也可用默认访问组）。
2. 管理员创建只读管理账号，设置至少 10 字符的申请密码，并选择所属组。账号独立于编辑账号，不能登录编辑工作台。
3. 只读端设置中先保存服务器地址，在「设备访问授权」填写账号、密码、设备显示名称，发送加入申请。名称默认使用计算机名称，可以修改。账号密码只在申请时发送，不保存到本地。
4. 管理员刷新设备申请列表，核对名称、账号、组后批准或拒绝；批准后客户端下次刷新同步，也可点击检查审批状态。
5. 管理员可撤销单台设备授权、停用整个账号或组。服务端对每次读取检查状态；客户端下次刷新隐藏记录，明确拒绝时不再回退显示缓存。

各访问组管理设备准入，共享现有记录库，不按组拆分物品。每台客户端以随机独立凭证注册，服务端只存 SHA256 哈希；客户端使用 Electron safeStorage/Windows 用户凭据加密存放在配置目录的 devices 子目录，并按服务器地址隔离。新设备及重新申请均需批准。更改申请密码用于后续申请，已批准的设备保留授权；停用账号可统一撤销访问。

记录、图片和 cache-status 读取现在需要编辑者/管理员会话或已批准设备凭证。设备只可读未认领完整记录及其关联图片；已认领记录仅返回缓存清理所需状态元数据。未关联的上传图片也不向设备提供。图片响应 private, no-store，防止共享缓存绕过授权。

断网时曾获批准的设备仍可查看本地缓存，无法即时获知远端撤权；恢复连接后检查。授权控制服务端读取和新版界面显示，无法收回已复制的缓存、截图或旧客户端副本。跨机器搬移程序后应重新申请，设备凭据绑定 Windows 用户加密环境。远程或公网传输账号密码与设备凭证应使用 HTTPS。

新增测试：laf-backend/scripts/devices-smoke.mjs（52 项）；laf-desktop/scripts/devices-gui-smoke.cjs（网页创建组/账号、具名申请、批准同步、加密凭据、断网缓存与撤权隐藏），均使用独立 8790/.test-state 测试服务与测试 profile。
